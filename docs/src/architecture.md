# Architecture

The scaffold produces a **two-layer client**:

- **`src/api/`** — generated by [OpenAPI Generator](https://openapi-generator.tech/)
  (`julia-client`), committed to the repo as plain Julia source.
  Java is needed *only* when scaffolding or regenerating; end users of
  the package will never need it.
- **`src/client/`** — hand-written ergonomic overlay. Wraps the
  generated `OpenAPI.Clients.Client`, adds auth strategies, composable
  reliability primitives, pagination iterators, and pretty `show` for
  generated model types.

## Why two layers

The `julia-client` generator is BETA and produces low-level bindings:
each operation is a method on an API-set struct (e.g.
`get_pet_by_id(::PetApi, ::Int64)` rather than a free function), and
auth schemes beyond bearer/basic/api-key aren't supported. The
hand-written layer exists to absorb those rough edges:

- Free-function ergonomics via `using .GeneratedAPI` re-exports
- OAuth2 / SigV4 / signing schemes implemented as `Auth` subtypes that
  inject headers via `pre_request_hook`
- Reliability stack (`with_defaults`) composes around any generated
  endpoint call, no per-endpoint plumbing required
- Typed errors map non-2xx responses to `APIError` subtypes so callers
  pattern-match instead of inspecting integers

## Scaffold pipeline

The `APIWrapper` factory composes five `OpenAPITemplate` plugins on top
of the standard PkgTemplates plugins (`ProjectFile`, `SrcDir`, `Readme`,
`License`, `Git`, `Formatter`, `GitHubActions`, `Codecov`,
`CompatHelper`, `TagBot`). Each runs in a `posthook` at a specific
priority:

| Priority | Plugin | What it writes |
| --- | --- | --- |
| 200 | `ClientLayer` | `src/<PKG>.jl`, `src/client/{auth,errors,retry,rate_limit,timeout,logging,middleware,Client,pagination,show}.jl`, runtime deps in `Project.toml`, custom `README.md`, `.gitignore` extras |
| 100 | `OpenAPISpec` | (only if `spec_url` set) saves `spec/openapi.json`, normalises to OAS 3, runs codegen, writes `gen/{openapi-config.json,regenerate.jl}`, `scaffold-info.toml`, `.gitattributes`, drift-check workflow |
| 50 | `BrokenRecordTests` | Full `test/` tree (auto-walking `runtests.jl` + per-component test files + opt-in cassette / mocking skeletons) |
| 25 | `VitepressDocs` | `docs/{Project.toml,package.json,make.jl}`, `docs/src/{index,getting_started,julia_reference,cassette_testing}.md`, per-tag `docs/src/api/<tag>.md` (built at make-time from the spec), GitHub Pages workflow |
| 5 | `Git` | initial commit, `.gitignore` (with extras contributed via `gitignore(::ClientLayer)`) |

`ClientLayer` runs first so subsequent plugins find a consistent module
file to extend; `Git` runs last so it sees the finished tree.

## Dependency model — who needs what, when

| Audience | Needs |
| --- | --- |
| Maintainer running `Template(...)` | Julia 1.10+, Java 11+, Node 18+ (for `npx`) |
| Maintainer running `gen/regenerate.jl` | Java 11+, Node 18+ |
| End user of the generated package | Julia 1.10+ — that's it |
| CI of the generated package | Julia (matrix); Node only on the docs job |
| The `regen-check.yml` weekly drift workflow | Java + Node (gated by `if:` to skip on PR builds) |

The promise: end users do not need Java. The committed `src/api/` is
plain Julia; the generator's job is finished by the time the package
is published.

## Generated module layout

```text
PetstoreClient/
├── src/
│   ├── PetstoreClient.jl          # `module PetstoreClient ... end`
│   ├── api/                       # GENERATED — DO NOT EDIT
│   │   ├── PetstoreClientAPI.jl
│   │   ├── modelincludes.jl
│   │   ├── apis/                  # one struct per spec tag
│   │   └── models/                # one mutable struct per spec schema
│   └── client/
│       ├── auth.jl                # NoAuth/BearerToken/APIKey/BasicAuth
│       ├── errors.jl              # APIError hierarchy + check_response
│       ├── logging.jl             # with_logging, redact_headers
│       ├── retry.jl               # RetryPolicy, with_retry, backoff_delay
│       ├── rate_limit.jl          # TokenBucket, acquire!, with_rate_limit
│       ├── timeout.jl             # with_timeout
│       ├── middleware.jl          # default_middleware, with_defaults
│       ├── Client.jl              # the user-facing struct
│       ├── pagination.jl          # paginate_cursor/offset/pagenum
│       └── show.jl                # pretty MIME"text/plain" for APIModel
├── spec/
│   ├── openapi.json               # canonical OAS 3 form (committed)
│   └── openapi.v2-original.json   # original Swagger 2.0 (if applicable)
├── gen/
│   ├── openapi-config.json        # pinned generator version + options
│   └── regenerate.jl              # `julia gen/regenerate.jl` to refresh
└── scaffold-info.toml             # spec URL + generator version + timestamp
```
